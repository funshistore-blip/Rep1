✨ Luxury Todo List
A stylish, responsive Todo List application built with HTML, CSS, and JavaScript. Organize daily tasks with an elegant sticky-note interface, track due dates, and keep your tasks saved between visits.
Features
Add tasks — create tasks with an optional due date.
Edit tasks — update a task when plans change.
Complete tasks — mark finished tasks as completed.
Delete tasks — remove tasks you no longer need.
Filter tasks — view all, active, or completed tasks.
Task counters — see how many tasks remain and how many are completed.
Due-date indicators — identify tasks that are due today or overdue.
Persistent storage — tasks are saved in your browser using `localStorage`.
Dark mode — switch between light and dark themes.
Luxury sticky-note styling — pastel notes, gentle rotations, soft shadows, and hover animations.
Responsive layout — adapts to desktop and mobile screens.
Built With
HTML5 — page structure and semantic elements
CSS3 — layout, responsive styling, sticky-note effects, and themes
JavaScript — task interactions, filtering, date handling, and local storage
No framework or build tool is required.

How to Use
Enter a task in the input field.
Optionally choose a due date.
Select Add Task.
Use the task controls to edit, complete, or delete a task.
Select All, Active, or Completed to filter the list.
Use the theme toggle to switch between light and dark mode.
Tasks and theme preferences are stored locally in the browser. They are not automatically synced between browsers or devices.
Design Highlights
The interface uses a refined, warm visual style with pastel sticky notes, subtle rotations, soft shadows, and hover effects. The layout is designed to remain usable on smaller screens, while dark mode provides an alternative low-light appearance.
